# SMS Spam Detection using Transfer Learning with BERT

## Project Description

This project detects whether an SMS message is **Spam** or **Ham (Not Spam)** using a fine-tuned BERT model from Hugging Face.

## Project Features

- SMS Spam Detection
- Transfer Learning with BERT
- Hugging Face Model Hosting
- Streamlit Web Application

## Dataset

UCI SMS Spam Collection Dataset

## Pretrained Model

bert-base-uncased

## Hugging Face Model

https://huggingface.co/gulpara/sms-spam-detection

## Technologies Used

- Python
- Transformers
- Hugging Face
- PyTorch
- Streamlit

## How to Run

```bash
pip install -r requirements.txt
streamlit run app.py
```
